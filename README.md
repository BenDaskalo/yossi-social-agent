# יוסי סושיאל אייג'נט 🎬

מנהל תוכן אישי עם זיכרון ולמידה עצמית — מיועד ליוסי אליהו.

## מה הסוכן עושה
- כותב תסריטים לסרטוני אינסטגרם בסגנון שלך
- סורק מתחרים ולומד מה עובד
- זוכר כל תיקון שאתה נותן ולא חוזר על טעויות
- משתפר עם כל שיחה

## התקנה

### 1. שכפל את הפרויקט
```bash
git clone https://github.com/YOUR_USERNAME/yossi-social-agent.git
cd yossi-social-agent
```

### 2. התקן תלויות
```bash
pip install -r requirements.txt
```

### 3. הגדר API Keys
```bash
cp .env.example .env
```
פתח את קובץ `.env` והכנס את המפתחות:
- `ANTHROPIC_API_KEY` — מ-console.anthropic.com
- `APIFY_API_KEY` — מ-console.apify.com (יש לך אחד כבר)

### 4. הפעל
```bash
python agent.py
```

## פקודות

| פקודה | מה עושה |
|-------|---------|
| `סרטון <נושא>` | כותב תסריט חדש |
| `סרטון <נושא> --דפוס mystery_short` | כותב עם דפוס ספציפי |
| `סרוק <@username>` | סורק ומנתח מתחרה |
| `אשר <מספר>` | מאשר תסריט — הסוכן לומד ממנו |
| `שפר <מספר>` | משפר תסריט לפי הפידבק שלך |
| `למד <טעות> \| <נכון>` | שמור תיקון ידני |
| `כלל <כלל>` | שמור כלל סגנון |
| `תסריטים` | הצג כל התסריטים |
| `פידבק` | הצג כל מה שנלמד |

## דפוסי תוכן

| שם | תיאור |
|----|-------|
| `mystery_short` | וידאו 12 שניות, הוק מסתורי |
| `myth_bust` | אתגור מיתוס בתחום + הוכחה |
| `big_brand_story` | ניתוח מותג גדול + דעה |
| `personal_story` | סיפור אישי אמיתי |
| `answer_audience` | תשובה לשאלת קהל |

## זיכרון

הסוכן שומר הכל בתיקיית `memory/`:
- `profile.json` — הפרופיל שלך
- `feedback.json` — כל התיקונים והכללים שנלמדו
- `approved_scripts.json` — תסריטים מאושרים
- `competitor_insights.json` — מחקר מתחרים

**לא נדרשת הגדרה נוספת — הסוכן לומד ממך בשיחה.**
